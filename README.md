## 🧾 Deskripsi Proyek

Proyek ini bertujuan untuk membandingkan **efisiensi algoritma iteratif dan rekursif** dalam menyelesaikan permasalahan perhitungan **total tabungan bulanan** yang dimodelkan sebagai penjumlahan deret bilangan dari 1 hingga *n*.

Studi kasus ini diangkat dari aktivitas menabung dalam kehidupan sehari-hari, di mana jumlah tabungan meningkat secara bertahap setiap bulan dengan jumlah taumlah uang yang ditabung setiap bulannya itu sama dengan jumlah tabungan awal. Program ini menghitung total tabungan, mengukur waktu eksekusi kedua algoritma, serta menampilkan hasil dalam bentuk **tabel dan grafik perbandingan**.

---

## 🧮 Konsep Perhitungan

Jika tabungan awal per bulan = **X** dan jumlah bulan = **n**, maka:

```
Total Tabungan = (1 + 2 + 3 + ... + n) × X
```
